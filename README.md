# Autossential.Activities

Autossential.Activities extends the native UiPath activity set with practical, reusable building blocks designed to simplify automation development. It reduces repetitive coding and helps keep workflows clean, efficient, and easy to maintain.

✨**Key categories of activities:**

- Data: Advanced DataTable and dictionary manipulation (promote headers, transpose data, remove empty rows, update dictionaries).
- Files: Streamlined file and folder operations (cleanup, wait for files, zip/unzip).
- Programming: Minimize custom code with utilities like culture scope, token replacement, parsing, and data merging.
- System: Tools for drive mapping and process management.
- Workflow: Enhanced flow control (conditions, timed loops, checkpoints, controlled exits).

📄**Full documentation available at:** [https://autossential.github.io](https://autossential.github.io)

🚀 **Installation**

Autossential.Activities is available on NuGet. To install in UiPath:

1. Open UiPath Studio.
2. Go to Manage Packages (top ribbon or right-click project → Manage Packages).
3. In the NuGet / All Packages feed, search for Autossential.Activities.
4. Select the package and click Install.
5. Save your project — the activities will now appear in the Activities Panel.
